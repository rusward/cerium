# Logo

- `cerium-logo.png` — the current Cerium logo: a monochrome pixel mascot holding the Ce
  element tile. It is used in the README header and as the source for the website favicon.

The website uses the logo **only as the browser tab icon** (`website/docs/assets/cerium-favicon.png`);
there is no logo in the page header or hero. Final icon variants can be added here later.
