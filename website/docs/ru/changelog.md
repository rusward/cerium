# История изменений

Все заметные изменения Cerium описаны в этом файле.

## [0.5.0] - 2026-11-22

### Добавлено

- двуязычный сайт документации в `website/` на MkDocs Material, публикуемый на GitHub Pages.

### Изменено

- **BREAKING:** проект переименован из Hydrogen в Cerium, потому что старое имя уже
  использовалось другим языком;
- расширение исходников изменено с `.hy` на `.ce`;
- команда компилятора и Python-пакет переименованы с `hydrogenc` на `ceriumc`;
- префикс C-рантайма изменён с `hy_` на `ce_`, `HY_FILE` — на `CE_FILE`;
- вся пользовательская документация переведена на английский;
- репозиторий GitHub переехал с `rusward/hydrogen` на `rusward/cerium`.

## [0.4.0] - 2026-11-22

### Добавлено

- явные преобразования: `toString(value)`, `toInt(text)`, `toDouble(text)`, `toBool(text)`;
- форматирование чисел в строку как в `log` (`%g` для `double`);
- ошибки рантайма при неверном вводе для преобразований;
- `examples/conversions.ce` и тесты преобразований.

## [0.3.0] - 2026-11-22

### Добавлено

- встроенные функции консольного ввода: `input()`, `inputInt()`, `inputDouble()`,
  `inputBool()`;
- необязательный строковый промпт, который печатается и сбрасывается перед чтением;
- типизированный разбор с ошибками рантайма при неверном вводе и неожиданном EOF;
- `examples/input.ce` и end-to-end тесты, подающие stdin в собранные программы.

## [0.2.0] - 2026-11-22

### Добавлено

- пользовательские функции: `func name(...) -> type`, возврат `void`, рекурсия;
- вызовы вперёд и взаимная рекурсия через предварительный сбор сигнатур;
- объявления `struct`, литералы структур без `new`, доступ и присваивание полей;
- структуры как параметры и возвращаемые значения, передача по значению;
- C-подобные циклы `for` с областью видимости инициализации;
- бесконечный `loop` с `break` и `continue`;
- анализ отсутствующего возврата для non-void функций;
- тесты функций, структур, циклов и новых ошибок;
- `docs/syntax.md`: руководство по синтаксису для v0.2;
- метаданные пакета (`pyproject.toml`), CI и лицензия MIT;
- референс логотипа в `logo/`.

### Изменено

- целями присваивания теперь могут быть поля: `p.x = value;`;
- вызовы можно использовать как операторы, даже если они возвращают значение;
- `SPEC.md` обновлён под грамматику и семантику v0.2.

### Исправлено

- деление и остаток на ноль теперь сообщают точную строку в `.ce`;
- переполнение `int` использует определённые хелперы заворота по доп. коду.

## [0.1.0] - 2026-11-22

### Добавлено

- лексер, рекурсивный парсер и AST начального языка;
- статическая проверка типов с блочными областями видимости и несколькими диагностиками;
- C99-бэкенд, драйвер gcc, `#line` и рантайм-хелперы;
- скалярные типы `int`, `double`, `bool`, `string`;
- `if`/`else if`/`else`, `while`, `log(...)`;
- CLI: `build`, `check`, `emit-c`, `--version`;
- модульные и end-to-end тесты;
- примеры и начальная документация.
